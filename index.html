FROM AN IDEA TO A LITTLE LOOP

Make something
move.

Bring a transparent 3D still. Give it a motion that makes sense. Our small, local toolkit handles the frames, alpha and tiny AVIF.

Read the generation guide ↗
01

Start with a character.

Scaffold an asset, write a precise prompt, and save your original transparent PNG.

npm run new -- your-emoji
02

Give it the right kind of motion.

A leaf sways. A soft peak wobbles. A solid bowl stays put. Tune a small recipe.

npm run animate -- your-emoji
03

Review. Then let it out.

Check the loop on light and dark backgrounds. Approve it and rebuild the catalog.

npm run review -- your-emoji
